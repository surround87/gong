# GONG

Vocal workout PWA (allenamento vocale). Next.js (App Router, static export)
+ TypeScript, no backend — the whole app is a client-side workout timer.

## Structure

- `app/` — Home screen (`/`) and the Player screen (`/player`).
- `components/PlayerScreen.tsx` — the interactive player: countdown timers,
  tap-to-close-a-set, long-press-to-pause. State machine lives in
  `lib/useWorkoutSession.ts`; the demo session data is in `lib/workout.ts`.
- `public/manifest.json`, `public/sw.js`, `public/icons/` — PWA install +
  offline support. Icons are generated by `scripts/generate-icons.mjs`
  (pure Node, no image-library dependency — rerun with `npm run icons` if
  you want to change them).
- `public/design/` — the original Claude Design "Passaggio 2 · Player"
  design-review page (all eleven states + design rationale), kept as
  in-repo reference. Unrelated to the app's routing; open it directly at
  `/design/index.html`.

The visual language (colors, Archivo at `font-stretch: 70%`, the flip/
rising-field animations) and the demo session (tabata → recovery → rep sets
→ circuit) are ported 1:1 from `public/design/index.html`'s prototype.

## Running locally

This machine has no system Node.js/npm — a user-scoped copy lives at
`~/.local/nodejs` (installed once; nothing systemwide was touched).

```bash
export PATH="$HOME/.local/nodejs/bin:$PATH"
npm install     # first time only
npm run dev     # http://localhost:4321
```

`npm run build` produces a static export in `out/` — that's what deploys to
Vercel.
